Python OOP implementation of a Research Submission with both the original and optimised versions included in the same repository.

🛠 Technologies
- Python
- Streamlit
- Object-Oriented Programming (OOP)


▶️ Run the Project

Install dependencies:
- pip install -r requirements.txt

Run either system:
1. cd Original
2. source venv/bin/activate   
3. streamlit run app.py

or

1. cd Optimised
2. source venv/bin/activate   
3. streamlit run app.py
